# Открытый мир привязок

Каталог понятий — словарь допустимого смысла, не полный перечень строк банковской модели. Строка новой комиссии, транша, особенности ковенанта или компонента денежного потока может не совпасть ни с одним понятием. Назначать ей ближайшее понятие опасно: похожая подпись ещё не та величина.

Нормативная таблица статусов — [design-v0.23.md](design-v0.23.md) §5.10.1. Этот документ фиксирует инвариант, который не должен сузиться, когда каталог метрик растёт.

## Статусы

У каждой fact-строки ровно один статус:

| Статус | Смысл |
|---|---|
| `bound` | понятие выбрано, проверки прошли |
| `bound_with_warning` | понятие выбрано, есть предупреждение |
| `ambiguous` | кандидаты есть, одного победителя нет |
| `unknown` | содержательная строка без понятия |
| `not_applicable` | служебная или исключённая строка |
| `ignored` | человек подтвердил «не понятие» |

`bound` и `bound_with_warning` — единственные статусы, из которых коэффициент берёт основную строку. Остальные четыре — отказ от привязки. В коде это `ACCEPTED` и `ABSTAIN` в `src/finance_analysis/domain/evaluation.py`.

## Что словарь может и чего не может

- Понятие вне каталога записать нельзя. `check_derived` отвечает `concept_not_in_catalog`.
- Пустое понятие законно. `unknown` хранится строкой с `concept = None`, а не выпадает из `bindings`.
- Точная метка глоссария может дать `bound`. Это совпадение со словарём, не ближайший сосед.
- Уверенный модельный кандидат (высокая вероятность и достаточный отрыв) может дать `bound`. Один только косинус до ближайшего понятия — не может.
- У `ambiguous` имя верхнего кандидата может лежать в `concept`. `is_primary` при этом ложь, и DSCR по этой строке не считается.
- У `unknown` после порога NIL `concept is None`.

Сборка — `decide` и `assign_rows` в `src/finance_analysis/domain/mapping.py`. Расчёт не подставляет молчаливый ноль вместо отсутствующего понятия: `coverage_ratio` отдаёт `needs_input`.

## Чего этот инвариант не делает

Предложение в очередь глоссария (`synonym_of` ближайшего понятия, пока человек не принял) привязку строки не меняет. Пороги `accept`, `gap`, `tau_nil`, `delta_nil` этот документ не пересматривает. Каталог метрик не становится вторым источником правды о строке: он описывает коэффициенты, а не обязанность найти понятие для каждой строки листа.
