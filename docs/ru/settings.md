# Настройки

[English](../en/settings.md)

FAS читает каждое имя ниже из окружения и из `.env` в рабочем каталоге. Значение из окружения перекрывает `.env`. Строка, которая начинается с `#`, не читается. `cp .env.example .env` включает только строки без `#`.

`FAS_HOST_PORT` по умолчанию `8088`, `BUILDER_HOST_PORT` по умолчанию `8080`. Эти два имени читает Compose из shell, когда публикует порты. Полями `Settings` они не являются. API публикуется на `127.0.0.1:8088`. Билдер публикуется на `127.0.0.1:8080`.

`appendonly yes`, `appendfsync everysec` и `maxmemory-policy noeviction` — команда сервиса `redis` в `deploy/docker-compose.override.yml`. Переменными приложения они не являются.

## Процесс

| Имя | По умолчанию | Что делает процесс |
| --- | --- | --- |
| `FAS_REDIS_URL` | нет | Обязательна. Старт не проходит, если она пустая, Redis не отвечает или сервер старше 8.6.5. Путь URL — логическая база. У FAS это база `1`. |
| `FAS_DATA_DIR` | `./data` | Каталог, когда S3 выключен. Путь хранилища — этот каталог плюс `FAS_S3_PREFIX`. |
| `FAS_HOST` | `127.0.0.1` | Адрес, который слушает `uvicorn`. Compose внутри контейнера ставит `0.0.0.0` и публикует только `127.0.0.1:8088`. |
| `FAS_PORT` | `8080` | Порт, который слушает `uvicorn`. |
| `BUILDER_BASE_URL` | пусто | Базовый URL HTTP API билдера. Пустое значение обрывает каждый вызов билдера сообщением «BUILDER_BASE_URL не задан». Прод-compose ставит пустую строку, чтобы скопированный `.env` не отправил контейнер к самому себе. Локальный override ставит `http://finance-context:8080`. |
| `FAS_EMBEDDED_WORKERS` | `false` | `true` запускает четыре процесса `fas-worker` и `fas-scheduler` детьми `fas-api`. `false` оставляет очереди процессам, которые запускаете вы. Compose ставит `true`. Ребёнок завершается, если pid, который его породил, уже не родитель, кроме случая, когда этот родитель — PID 1. |
| `FAS_IN_CONTAINER` | `false` | Compose ставит `true`. Хост Redis `127.0.0.1`, `localhost` или `::1` тогда ломает старт. Для `uv run fas-api` не задавайте. |
| `FAS_EMBEDDED_RESTART_BACKOFF_SEC` | `1` | Секунды, которые супервизор ждёт, прежде чем снова поднять умершего ребёнка. Значение больше 0. |
| `FAS_ADMIN_TOKEN` | пусто | Пустое значение разрешает запись релиза глоссария. Любое другое требует заголовок `x-admin-token` с тем же значением. |
| `FAS_REQUIRE_ADMIN_TOKEN` | `false` | Fail-closed профиль прода. `true` ломает старт процесса, если `FAS_ADMIN_TOKEN` пуст, поэтому привилегированная запись в глоссарий всегда требует `X-Admin-Token`. Для local/dev оставляйте `false`. |
| `FAS_READ_ONLY` | `false` | `true` запрещает записи в хранилище. Самотест условной записи пропускается. |
| `FAS_EVAL_DIR` | `eval` | `fas eval` читает метки из `FAS_EVAL_DIR/labels` и, если есть, ещё сливает `FAS_EVAL_DIR/local/labels` (клиентские книги вне git). |
| `LOCK_TTL_MS` | `60000` | Срок блокировки книги и блокировки GC. Также нижняя граница TTL незавершённого ключа идемпотентности. |
| `LOAD_SYNC_SEC` | `20` | Сколько `POST /v1/books/{job_id}:load` ждёт билдера. Незавершённый ключ идемпотентности живёт не меньше этих секунд плюс 30. |
| `ETAG_TTL` | `300` | Секунды, которые кэш находок лежит в Redis. |

## Хранилище

S3 включён, только когда заданы все три: `FAS_S3_BUCKET`, `FAS_S3_ACCESS_KEY` и `FAS_S3_SECRET_KEY`. Любой меньший набор — ошибка старта. С endpoint источник Wren — `minio_file`. Без endpoint — `s3_file`. Без S3 источник — локальный каталог.

| Имя | По умолчанию | Что делает процесс |
| --- | --- | --- |
| `FAS_S3_ENDPOINT` | пусто | URL MinIO или совместимого S3. Если задан, Wren использует `minio_file`. |
| `FAS_S3_BUCKET` | пусто | Имя бакета. Одно из трёх полей, которые включают S3. |
| `FAS_S3_PREFIX` | `fas` | Префикс ключа в бакете. На диске это каталог внутри `FAS_DATA_DIR`. |
| `FAS_S3_ACCESS_KEY` | пусто | Ключ доступа. Одно из трёх полей, которые включают S3. |
| `FAS_S3_SECRET_KEY` | пусто | Секрет. Одно из трёх полей, которые включают S3. |
| `FAS_S3_REGION` | `us-east-1` | Регион, который уходит в Wren `s3_file`. `minio_file` его не получает. Локальный MinIO в Compose — `ap-northeast-1`, для этого сервера значение надо задать. |
| `FAS_S3_SSL` | следует за endpoint | Незаданное становится `false` только для endpoint с `http://`. Пустой endpoint, `https://` и хост без схемы остаются `true`. Явные `true` и `false` сохраняются. Wren `minio_file` берёт его как `ssl_enabled`. |

## Wren

Число живых движков — меньшее из `WREN_ENGINE_POOL` и `WREN_POOL_MEMORY_MB / WREN_DUCKDB_MEMORY_MB`, и не меньше 1. На этом пределе закрывается самый старый движок, которым никто не пользуется.

| `WREN_DUCKDB_MEMORY_MB` | `512` | `SET memory_limit` на каждом соединении DuckDB. Больше 0. |

## Периметр auth (prod)

FAS **не** аутентифицирует вызывающих. `X-User-Id` и `X-Client-Id` — непрозрачные метки для аудита, квот и идемпотентности, а не доказательство личности, в том числе в проде. Gateway/mTLS в этом срезе нет.

Fail-closed профиль прода для привилегированной записи в глоссарий:

1. Задать непустой `FAS_ADMIN_TOKEN`.
2. Задать `FAS_REQUIRE_ADMIN_TOKEN=true`, чтобы старт падал без токена.
3. На релизы / переходы / откат / `proposals:decide` передавать совпадающий `X-Admin-Token`.

Локально и в CI оставляйте `FAS_REQUIRE_ADMIN_TOKEN` выключенным и можете не задавать `FAS_ADMIN_TOKEN` (гейт админа выключен). Маршруты книг и анализов остаются открытыми во внутренней сети; флаг не добавляет user auth.
